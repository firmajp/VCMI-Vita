# Corresponding source — 1.0.0-rc.1

The complete GitHub source ZIP contains this version's VPK in dist/, engine in src/vcmi, full relevant library sources in third_party/, dependency recipes, original notices, and build/packaging/install scripts. Keep it available alongside every matching VPK download. An unrelated upstream tree or a later branch is not a substitute for the matching version's source.

The linked work uses GPL-3.0-or-later; individual files retain their component licenses. pthread-embedded and FFmpeg follow LGPL 2.1 section 6(a): complete library and application source plus build/relink material is supplied. Users may modify the libraries and reverse engineer the linked work to debug those modifications. The project adds no contrary restriction or signing-key requirement. See BUILDING.md and PTHREAD_LINKING.md.

Compiler/SDK binaries and proprietary system modules are excluded. Original copyright and author notices are retained. Original game data, demonstration media/test maps, unused Apple frameworks/JARs and optional test corpora are excluded and unnecessary for this Vita client configuration; see SOURCE_DISTRIBUTION_EXCLUSIONS.json. No end-user Data/Maps/Mp3 folder may be uploaded with this project.

Every changed binary must be accompanied by its corresponding changed source/build material and refreshed provenance/checksums. The first RC is based on the user-tested v038 implementation and rebuilt from the exported tree; the original exact RC1 has passed the user-reported checklist; this artwork-only repack needs its new LiveArea installation/visual check. This distinction is retained in the evidence.

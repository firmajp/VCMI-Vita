# Source provenance and AI assistance

This repository primarily contains the existing VCMI engine and third-party libraries. Their upstream authorship, license notices and recorded source revisions remain applicable. It is inaccurate to describe that upstream code as entirely AI-generated.

The Vita adaptation, local debugging, optimization work and packaging/documentation were developed with AI assistance. This disclosure does not establish that every new expression is copyrightable, grant ownership of third-party code, or prove the absence of unattributed similarities. New project files are offered under the stated project terms only to the extent the distributor holds applicable rights. Existing third-party notices are retained.

`SOURCE_MANIFEST.json`, dependency recipes, original file headers and `MODIFICATIONS.md` record available origins and changes. Internal ScanCode license-scan outcomes and interpretations are recorded in `docs/compliance/SCANCODE_REVIEW.json`; no independent authorship/provenance audit is claimed. A scanner can help identify license notices and suspicious matches; it cannot certify authorship or exclude all code reproduction.

The public artwork is documented in `ARTWORK_PROVENANCE.md`. The release preserves the user-tested executable and runtime assets; current build/source hashes identify the actual package. Historical development records are kept separate from current checks.
